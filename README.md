# excel-financial-dashboard
Interactive Excel dashboard for analyzing sales, profit, discounts, customer segments, and yearly business performance using Pivot Tables, Charts, KPI Cards, and Slicers.
## Project objective
The objective of this project is to analyze and visualize financial and sales data using Excel by cleaning the dataset and creating Pivot Tables, Charts, and Slicers to identify sales trends, profitability, customer segment performance, discount impact, and yearly business insights.
